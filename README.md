# DifColl  

**DifColl** — это современное приложение для управления коллекциями книг, фильмов и игр с социальными функциями. Оно упрощает создание, управление и обмен коллекциями, добавляя социальные возможности, такие как друзья и рекомендации.

## Возможности  

- **Управление коллекциями**: Создавайте и редактируйте собственные коллекции книг, фильмов и игр.  
- **Интеграция с API**: Автоматическое получение данных с Google Books, TMDb и RAWG для удобного добавления элементов.  
- **Социальные функции**: Делитесь коллекциями и следите за активностью друзей.  
- **Профиль пользователя**: Настройте фото, никнейм, биографию, интересы и социальные ссылки в своем профиле.  
- **Рекомендации**: Получайте персональные рекомендации на основе ваших интересов и коллекций.  

## Основные особенности  

- **Аутентификация**: Вход с помощью Google, Microsoft или же Twitter и управление доступом с ASP.NET Core Identity.  
- **Интуитивный интерфейс**: Простота использования с современным дизайном и адаптивной версткой.  
- **Реактивность**: Fetch API для мгновенного обновления данных.  
- **Модульная архитектура**: Компоненты и страницы для улучшения читаемости и поддержки кода.  

## Технологии  

- **Frontend**: React с использованием чистого JavaScript.  
- **Backend**: ASP.NET Core 8 с Entity Framework Core и ASP.NET Identity.  
- **База данных**: MSSQL для хранения пользователей, коллекций и элементов.  
- **API-интеграции**: Google Books, TMDb и RAWG для книг, фильмов и игр.  
- **Почта**: Google, Microsoft и Twitter Api для отправки писем с подтверждениями.  
- **Стилизация**: CSS с акцентом на современный дизайн и анимации.  

## Установка  

1. Клонируйте репозиторий:

    
    git clone https://github.com/Newalgabe/DifColl
    

2. Перейдите в папку проекта:

    
    cd DifColl
    

3. Установите зависимости:

    
    npm install
    

4. Запустите приложение.


# Как пользоваться приложением

- **Регистрация и вход**: Возможность авторизации через Google, Microsoft или же Twitter для удобного доступа.  
- **Создание коллекции**: Интеграция API для добавления книг, фильмов и игр в личную библиотеку.  
- **Редактирование профиля**: Настройка личной информации, включая фото, никнейм и социальные ссылки.  
- **Социальное взаимодействие**: Просмотр коллекций друзей.  
- **Рекомендации**: Поиск новых элементов и получение персонализированных рекомендаций.
