# DifColl 🎉

**DifColl** — современное приложение для управления коллекциями книг, фильмов и игр с социальными функциями. Оно упрощает создание, управление и обмен коллекциями, добавляя возможности для взаимодействия, такие как друзья и рекомендации.

## 🚀 Возможности

- **Управление коллекциями**: Создавайте и редактируйте коллекции книг, фильмов и игр.
- **Интеграция с API**: Автоматическое добавление данных с Google Books, TMDb и RAWG.
- **Социальные функции**: Делитесь коллекциями и следите за активностью друзей.
- **Профиль пользователя**: Настройка личной информации, таких как фото, никнейм, биография и социальные ссылки.
- **Рекомендации**: Получайте персонализированные рекомендации на основе ваших интересов.

## 🔧 Основные особенности

- **Аутентификация**: Вход через Google, Microsoft или Twitter с использованием ASP.NET Core Identity.
- **Интуитивный интерфейс**: Простой и современный дизайн с адаптивной версткой.
- **Реактивность**: Использование Fetch API для мгновенного обновления данных.
- **Модульная архитектура**: Чистая и легко поддерживаемая структура с компонентами и страницами.

## 🛠 Технологии

- **Frontend**: React с использованием чистого JavaScript.
- **Backend**: ASP.NET Core 8 с Entity Framework Core и ASP.NET Identity.
- **База данных**: MSSQL для хранения пользователей, коллекций и элементов.
- **API-интеграции**: Google Books, TMDb и RAWG для книг, фильмов и игр.
- **Почта**: API для отправки писем с подтверждениями через Google, Microsoft и Twitter.
- **Стилизация**: Современный дизайн с использованием CSS и анимаций.

## 💻 Установка

Для того чтобы запустить приложение на своём локальном компьютере, выполните следующие шаги:

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/Newalgabe/DifColl
    ```

2. **Перейдите в папку проекта:**

    ```bash
    cd DifColl
    ```

3. **Установите зависимости:**

    ```bash
    npm install
    ```

4. **Запустите приложение:**

    ```bash
    npm start
    ```

## 📱 Как пользоваться приложением

1. **Регистрация и вход**: Авторизуйтесь через Google, Microsoft или Twitter для удобного доступа в приложение.
2. **Создание коллекции**: Добавляйте книги, фильмы и игры в свою коллекцию с помощью интеграций API.
3. **Редактирование профиля**: Настройте личные данные, такие как фото, никнейм, интересы и социальные ссылки.
4. **Социальное взаимодействие**: Следите за коллекциями друзей, обменивались рекомендациями.
5. **Рекомендации**: Получайте персонализированные рекомендации на основе ваших коллекций и интересов.

## 📂 Структура проекта

- **Frontend** — `src/`
    - `components/` — Компоненты интерфейса.
    - `pages/` — Страницы приложения.
    - `styles/` — CSS и стилизация.
    - `utils/` — Утилитарные функции и хелперы.
- **Backend** — `DifColl.Api/`
    - `Controllers/` — Контроллеры для обработки запросов.
    - `Models/` — Модели базы данных.
    - `Services/` — Логика работы с данными и внешними API.
- **Database** — `DifColl.Data/`
    - `Migrations/` — Миграции для базы данных MSSQL.
